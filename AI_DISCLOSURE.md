# AI-assisted development

This project was developed with substantial assistance from [OpenAI Codex](https://openai.com/codex/). AI assistance included source generation and modification, firmware/protocol investigation, reverse-engineering analysis, tests, build/release tooling, interface design and documentation.

The human owner set goals, supplied hardware, made product decisions and reported physical test results. AI-produced results can be incorrect. Neither AI assistance nor a passing automated test establishes a security review, legal review, electrical validation or support for other hardware revisions.

Physical test claims are limited to recorded user observations. Emulator results describe the modeled environment. New release artifacts require their own hardware checklist; changing version metadata changes the image hash.

The [REA skill/MCP](https://github.com/morluto/rea), [Ghidra](https://github.com/NationalSecurityAgency/ghidra) and TC32 tooling supported the investigation. See [attribution](ATTRIBUTION.md). No proprietary vendor executables or stock firmware are distributed here.

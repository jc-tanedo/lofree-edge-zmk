# Contributing

Use main as the primary branch and send pull requests against main. Run the checks in [development](docs/development.md). Keep changes scoped, update tests for behavior changes, and update the roadmap and user documentation when capabilities change.

Preserve copyright/license notices. Original contributions are GPL-3.0-or-later unless an existing per-file license applies. Disclose material AI assistance and verify generated claims. Do not submit vendor binaries, private device captures or keys.

This project is experimental and used entirely at your own risk. Hardware-dependent changes need reproducible steps, exact artifact SHA and honest differentiation between physical and emulator evidence.

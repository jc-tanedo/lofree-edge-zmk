## Required checks for this exact image

- [ ] ON: ordinary USB typing, Fn media, Caps fully on/off, backlight toggle/brightness.
- [ ] ON: Studio connect, physical unlock, read/edit/save mappings and three total layers.
- [ ] BT with USB attached: USB/Studio unavailable; existing profile reconnects and types.
- [ ] BT: fresh pairing on a spare profile, encrypted keyboard/media and Caps updates.
- [ ] BT: cable removal/insertion preserves Bluetooth operation without USB enumeration.
- [ ] OFF with USB: no input, advertising, indicator/backlight or USB data.
- [ ] OFF/BT/ON transitions and battery operation; return to ON restores USB/Studio.
- [ ] Held keys/modifiers during transitions leave neither host with stuck input.
- [ ] Legacy output actions cannot override ON/BT, including previously saved bindings.
- [ ] Retained-stock return and reinstall of this same image, without replacing the retained slot.
- [ ] Explicit flash self-test/acceptance, then saved mappings/layers/bonds after full power cycle.

## Trial handling

Each unconfirmed restart consumes the existing trial budget, including selector
restarts. Do not disable that protection. Hardware handoff must distinguish an
expected trial rollback from a transport failure. Repeated mode/power testing
requires a separately approved acceptance; state which checks are still pending
when requesting it. Acceptance writes flash and ends automatic rollback.

Keep the editor idle during device commands and installation. Freeze a separate
hash-named installer, finish independent checks first, and require a fresh risk
acknowledgment for each flash. Never overwrite the diagnostic installer on 8768.

Publication also requires the release checklist markers `switch-mode-routing`,
`switch-cable-battery` and `legacy-output-immunity`, tied to this exact SHA.

## Trial handling

Each unconfirmed restart consumes the existing trial budget, including selector
restarts. Do not disable that protection. Hardware handoff must distinguish an
expected trial rollback from a transport failure. Repeated mode/power testing
requires a separately approved acceptance; state which checks are still pending
when requesting it. Acceptance writes flash and ends automatic rollback.

Keep the editor idle during device commands and installation. Freeze a separate
hash-named installer, finish independent checks first, and require a fresh risk
acknowledgment for each flash. Never overwrite the diagnostic installer on 8768.

Publication also requires the release checklist markers `switch-mode-routing`,
`switch-cable-battery` and `legacy-output-immunity`, tied to this exact SHA.

## Evidence and limits

Owner reports cover ON USB typing, media, indicators, Studio edit/save; BT with
USB attached; fresh pairing on profile 3; unplugged battery use and cable
reinsertion; OFF suppression; Shift held across both ON/BT transition directions;
and legacy Bluetooth-output/USB-output bindings unable to override the slider.
Read-only host enumeration independently found zero Edge USB interfaces in BT
and OFF. Studio was inaccessible in both positions.

Fn+Space at BT restarted the keyboard; after moving ON the host identified stock
`EDGE84@Lofree`. The identical candidate was reinstalled. With explicit approval,
the flash self-test passed and confirmation changed trial count 1 to 0. After
OFF/unplug for five seconds/reconnect/ON, typing and saved maps/layers persisted;
readback still showed confirmed=yes, count=0 and valid retained-image size/CRC.
The saved Bluetooth profile then reconnected without re-pairing or profile
selection, and returning ON restored USB/Studio and disconnected Bluetooth.

This is owner-reported functional testing plus read-only device/host checks,
not an independent RF, electrical-current or supply measurement. Encryption,
all four output actions, GPIO preservation and stack margins also passed the
compiled-image emulator checks. Broader boards/hosts and sleep/battery sensing
remain outside this validation. Retained recovery is not guaranteed.

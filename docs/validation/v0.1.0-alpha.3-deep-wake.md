## Fix evidence and limits

The initial image failed the compiled pin-network regression: GPIO_PULL_UP
selects10k, leaving a pressed row at approximately91% VDD against a100k
column pull-down. The corrected compiled setup uses1M row pull-ups, giving
approximately9% VDD, and passes that regression. These are nominal resistor
calculations from compiled register state, not electrical measurements or
emulated deep wake. Fresh hardware validation remains required.

The [Fn+F12 cold-wake limitation](https://github.com/jc-tanedo/lofree-edge-zmk/issues/13)
is not addressed by this change. Current measurements remain unavailable.

Clean local preflight passed on the firmware commit above: all compiled tests,
including BT/OFF deep stack margins, both website bases and independent
source/history/archive/site audits. This is automated evidence only.
